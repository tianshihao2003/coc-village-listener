# 村庄JSON监听

《部落冲突》玩家工具：后台监听剪贴板，检测到游戏内复制的村庄数据 JSON 时，自动打开"村姑日记"并自动把每份数据存档到手机 `下载/村庄JSON/` 目录。

## 安装

1. 到本仓库 [Releases](../../releases) 页下载最新 `app-release.apk`；
2. 手机上点开安装，系统提示"未知来源"时选择继续/允许。

## 首次配置（一次性，约 5 分钟）

1. **安装 Shizuku**：手机浏览器打开 shizuku.rikka.app 下载；
2. **激活 Shizuku**（免电脑）：设置 → 开发者选项 → 打开"无线调试"，然后按本应用「激活引导」页操作；
3. **打开监听**：回到本应用点「开启监听」，允许权限弹窗；
4. **vivo 保活**：按「激活引导」页第四步设置后台白名单。

之后日常使用：游戏里点"复制" → 村姑日记自动打开，粘贴即可；每份数据同时存进手机下载目录。

## 注意

- 手机重启后 Shizuku 需重新激活（约 30 秒），本应用会在通知栏提醒；
- 本应用无任何联网权限，数据只存在手机本地；
- 目标软件默认预置"村姑日记"，可在应用内更换为任意应用；
- 首次使用建议点一下主界面的「剪贴板诊断」验证读取链路正常。

## 构建

```bash
./gradlew assembleRelease testReleaseUnitTest
```

签名使用仓库内 `release.keystore`（自用应用，密码公开存放于构建脚本；如需对外分发请自行更换）。
